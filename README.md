# bilibili Pro

bilibili Pro 是一个 Manifest V3 浏览器扩展，可在哔哩哔哩 / bilibili 视频和番剧播放页提供下载、队列、逐帧播放和自定义快进等增强功能。

## 功能说明

### 下载增强

- 下载当前分 P、全部分 P，或指定分 P 范围，例如 `1-3,5,8`。
- 支持清晰度选择，会优先使用当前账号可播放、接口可返回的最高可用清晰度。
- 支持合并音频和视频为 MP4，使用本地 ffmpeg wasm 完成封装。
- 支持轻量模式，不合并文件，只分别保存音频和视频流。
- 支持备用线路和自动重试，主线路失败后会尝试 B 站返回的备用媒体地址。
- 支持浏览器原生下载队列，可暂停、继续、取消、重试。
- 支持复制下载链接和复制诊断信息，方便排查下载失败原因。
- 支持文件名组合生成，可勾选标题、UP、BV、分 P、清晰度、日期。

### 播放控制

- 支持上一帧、下一帧逐帧播放。
- 按住上一帧或下一帧按钮时，可以连续逐帧播放。
- 支持自定义左右方向键快进秒数，也可以保留 B 站默认快进逻辑。
- 支持单次片段音画倒放：按 R 标记起点，继续播放后再按 R，从当前位置倒放回起点。

### 页面控制

- 提供原始 B 站排版和插件增强排版两种模式。
- 支持首页干净模式，隐藏部分干扰内容。
- 支持隐藏搜索热搜。
- 支持首页“换一换”历史回退，可恢复上一屏推荐。
- 支持 ESC 关闭图片预览。
- 支持封面/视频信息增强，悬停视频卡片可查看标题、BV、UP、播放、弹幕、时长等信息。
- 支持带鱼屏缩小修复，用于改善部分超宽比例视频在 P1 显示异常的问题。

### 视频总结

- 可显示“本视频重点”浮动面板。
- 支持 Top5、Top10、Top20 灵敏度。
- 优先参考 B 站原生热度数据，无法获取时再使用弹幕密度估算。
- 点击重点时间点可以跳转到对应播放位置。

### GIF 制作

- 支持按时间段制作 GIF。
- 支持逐帧卡点：上一帧、下一帧、设为起点、设为终点、跳到起点、跳到终点。
- 支持手动录制 GIF。
- 支持视频画面裁剪框，可拖动、缩放并选择局部区域。
- 支持帧率、尺寸、质量、裁剪比例设置。
- 默认参数偏向较小文件体积，适合快速截取片段。

### 截图增强

- 支持保存当前视频帧。
- 支持复制当前视频帧到剪贴板。
- 支持在浮窗“截图信息”tab 中查看和使用截图功能。
- 支持通过快捷键快速截图，默认 `C` 保存当前帧，`X` 复制当前帧。
- 适合截取视频画面、封面参考、台词画面和细节帧。
- 截图功能优先从页面 video 元素抽帧；如果当前视频受跨域限制，可能无法导出。

### 快捷键

- 可在浮窗中查看当前快捷键。
- 支持自定义逐帧、倒放、截图等快捷键。
- 默认快捷键：`,` 上一帧，`.` 下一帧，`R` 音画倒放，`C` 保存当前帧，`X` 复制当前帧。

### 工具栏

- 浏览器工具栏弹窗保留一键下载当前页面视频。
- 默认下载当前页面当前分 P。
- 默认尝试合并音频和视频为 MP4。
- 后台执行，不主动展开页面浮窗。

## Edge 安装

1. 打开 `edge://extensions/`
2. 打开“开发人员模式”
3. 点击“加载解压缩的扩展”
4. 从 GitHub Release 下载 `bilibili-pro-v版本号.zip`
5. 解压后选择解压出来的插件文件夹
6. 如果已经加载过旧版本，点击扩展卡片上的刷新按钮，或先移除后重新加载

注意：Release 页面里的 `Source code (zip)` 和 `Source code (tar.gz)` 是 GitHub 自动生成的源码包，不是插件安装包。安装插件请下载 `bilibili-pro-v版本号.zip`。

## Chrome 安装

1. 打开 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 从 GitHub Release 下载 `bilibili-pro-v版本号.zip`
5. 解压后选择解压出来的插件文件夹
6. 如果已经加载过旧版本，点击扩展卡片上的刷新按钮，或先移除后重新加载。

注意：Release 页面里的 `Source code (zip)` 和 `Source code (tar.gz)` 是 GitHub 自动生成的源码包，不是插件安装包。安装插件请下载 `bilibili-pro-v版本号.zip`。

## 使用提示

- 需要先登录 B 站账号，能播放的清晰度才通常能拿到下载地址。
- 如果合并下载占用太多内存，勾选“轻量模式”分别保存音频和视频。
- 如果要测试暂停/取消，建议先用“轻量模式”或单项下载，浏览器下载栏里也会同步出现任务。
- 下载队列依赖当前页面，请等队列完成后再关闭或刷新页面。
- 默认快捷键：`,` 上一帧，`.` 下一帧，`R` 音画倒放，`C` 保存当前帧，`X` 复制当前帧。
