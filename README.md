# bilibili Pro

bilibili Pro 是一个面向 Chrome / Edge 的哔哩哔哩 / bilibili 浏览器增强插件，提供视频工具箱、下载队列、逐帧播放、GIF 制作、截图增强、视频总结和页面优化等功能。

> 安装插件请下载 Release 页面中的 `bilibili-pro-v版本号.zip`。  
> `Source code (zip)` 和 `Source code (tar.gz)` 是 GitHub 自动生成的源码包，不是插件安装包。

## 功能亮点

### 下载增强

- 支持当前分 P、全部分 P、指定分 P 范围下载。
- 支持清晰度选择和最高可用清晰度下载。
- 支持合并 DASH 音频和视频为 MP4。
- 支持轻量模式，分别保存音频和视频流。
- 支持备用线路、自动重试、任务暂停、继续、取消、重试。
- 支持复制下载链接和复制诊断信息。
- 支持文件名组合生成：标题、UP、BV、分 P、清晰度、日期。

### 播放控制

- 支持上一帧、下一帧逐帧播放。
- 支持按住按钮连续逐帧播放。
- 支持自定义左右方向键快进秒数。
- 支持音画倒放。

### 页面控制

- 支持原始 B 站排版和插件增强排版。
- 支持首页干净模式、隐藏热搜、换一换历史回退。
- 支持 ESC 关闭图片预览。
- 支持封面/视频信息增强。
- 支持带鱼屏缩小修复。

### 视频总结

- 支持可拖动“本视频重点”面板。
- 支持 Top5、Top10、Top20 灵敏度。
- 点击重点时间点可跳转播放。

### GIF 和截图

- 支持时间段 GIF 制作和手动录制 GIF。
- 支持局部裁剪、帧率、尺寸、质量和比例设置。
- 支持保存当前帧和复制当前帧。
- 支持快捷键截图：默认 `C` 保存当前帧，`X` 复制当前帧。

### 快捷键和工具栏

- 支持查看和自定义快捷键。
- 工具栏保留一键后台下载当前页面视频，默认尝试合并 MP4。

## 安装方式

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 下载 Release 中的 `bilibili-pro-v版本号.zip`。
4. 解压 zip。
5. 点击“加载已解压的扩展程序”。
6. 选择解压出来的插件文件夹。

### Edge

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 下载 Release 中的 `bilibili-pro-v版本号.zip`。
4. 解压 zip。
5. 点击“加载解压缩的扩展”。
6. 选择解压出来的插件文件夹。
